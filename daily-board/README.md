# Daily Interview Prep Board

Use this folder as the daily operating board for interview preparation.

The goal is simple:

```text
Plan the day.
Do the work.
Record what happened.
Carry unfinished items forward.
Update XP honestly.
Track career XP and body XP together.
```

## Files

| File | Purpose |
|---|---|
| [today.md](today.md) | Current day's task board |
| [history.md](history.md) | Daily summaries of what was completed |
| [template.md](template.md) | Template for creating a fresh daily board |
| [interview-fitness-xp-tracker.xlsx](interview-fitness-xp-tracker.xlsx) | Excel tracker for career XP, fitness XP, bar graphs, topic progress, interview pipeline, and XP rules |

## Daily Routine

Morning or start of study session:

```text
1. Pick 3-5 realistic tasks.
2. Put them in today's board.
3. Mark the top 1-2 as priority.
```

During the day:

```text
Move tasks from Todo -> In Progress -> Done.
Write blockers clearly.
Do not keep adding random topics.
```

End of day:

```text
1. Write what was completed.
2. Write what was weak.
3. Write what carries forward.
4. Add one short confidence note.
5. Update XP start/end/delta.
```

## XP Rules

XP is not a judgment. It is a signal for what to practice next.

Core rule:

```text
XP goes up by practice.
XP stays same by rest.
XP goes down by neglect, failed recall, or bad habits.
```

Career topics use two XP scores:

```text
Practice XP  = calm/home ability
Interview XP = pressure + communication ability
```

Fitness stays single-score for now.

When studying at home:

```text
Practice XP goes up by revision or coding.
Interview XP goes up only when you explain aloud, do timed practice, or do a mock interview.
```

Example:

```text
Code Course Schedule calmly:
Practice XP +0.50

Explain Course Schedule aloud in 90 seconds:
Interview XP +0.25

Code it under 25 minutes without looking:
Practice XP +0.50
Interview XP +0.50
```

Use small changes:

```text
+0.25 = revised or explained once
+0.50 = coded or answered under timer
+1.00 = coded cleanly plus explained tradeoffs/failure cases
0.0  = no meaningful progress
```

Do not inflate scores after passive reading.

Prefer this rule:

```text
If I cannot explain it or code it without looking, XP should not move much.
```

Fitness XP follows the same idea:

```text
Workout done with decent effort      = meaningful XP
Protein/hydration target respected   = meaningful XP
Sleep target respected               = meaningful XP
Only planning without doing          = no meaningful XP
```

## XP Drop Rules

XP should not go down because of one normal bad day.

XP goes down only when a skill is getting rusty, avoided, or performed badly during review.

### No Drop For Planned Rest

Planned rest means maintenance.

```text
Sunday rest
family time
travel
heat exhaustion
recovery
```

These should usually be:

```text
0.0 change
```

### Career XP Drop Rules

Untouched topic:

```text
3 days untouched:       no drop
5-7 days untouched:     -0.25
10+ days untouched:     -0.50
2+ weeks untouched:     -1.00
```

Failed recall:

```text
Minor struggle:             -0.25
Could explain but not code: -0.50
Blank / confused:           -1.00
```

Random panic learning:

```text
Jump between many topics and finish nothing:
Overall interview readiness: -0.25
Mood / confidence:           -0.50
```

### Fitness XP Drop Rules

Workout consistency:

```text
Miss planned workout once with valid reason: no drop
Miss 2 planned workouts in a row:            -0.50
Miss 1 full week:                            -1.00
```

Steps / movement:

```text
One low-step day:       no drop
3 low-step days in row: -0.50
```

Protein / diet:

```text
One imperfect meal:              no drop
Full day poor protein/snacking:  -0.25 to -0.50
```

Hydration:

```text
One low hydration day: -0.25
Heat + low hydration:  -0.50
```

Sleep:

```text
One late night:       -0.25
3 bad nights in row:  -0.75 to -1.00
```

### Emotional Crash Rule

If rejection or harsh feedback hurts and one small useful action still happens, discipline XP does not drop.

Example:

```text
Got rejected.
Felt bad.
Still did 30 min BFS or walked/worked out.
Mood may be low, but discipline XP stays stable.
```

## Main XP Rule

```text
The XP sheet should be honest, not cruel.
```

The question is:

```text
Is this skill becoming stronger, stable, or rusty?
```

## Status Meaning

```text
Todo        = planned but not started
In Progress = currently being worked on
Done        = completed today
Blocked     = cannot continue without clarification, energy, or missing context
Carry Forward = important but not completed today
```

## Rule

Do not make the board huge.

For interview prep, a good day is usually:

```text
1 coding drill
1 concept revision
1 spoken explanation
1 project/system design answer
```
