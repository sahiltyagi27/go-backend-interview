# Common Interview Prep Strategy

Use this when preparing across GreyOrange, MAI Labs, and MongoDB.

## Overall Strategy

Prepare around common overlap instead of studying randomly.

Common areas across all three:

```text
Go backend development
Go concurrency
distributed systems
Kafka / async processing
MongoDB / database fundamentals
system design
production troubleshooting
project explanation
basic DSA patterns
```

Priority order right now:

```text
1. GreyOrange - may move fastest
2. MAI Labs - first interview already happened, possible follow-up
3. MongoDB - strongest brand and highest upside, but harder and likely slower
```

### Coding

```text
Go worker pool

```

### Backend Concepts


System design checklist:


## Project Explanation

Always be ready to explain:

```text
what the project was
what problem it solved
your role
tech stack
scale/traffic/data size if known
difficult technical challenge
production issue handled
performance improvement
tradeoffs
```

## Daily Study Routine

Every study day should include:

```text
1. one coding problem
2. one backend concept
3. one project explanation practice
4. one short revision note
```

Example day:

```text
Coding: Course Schedule
Backend: Kafka offset and DLQ
Project: Brevo cloud migration explanation
Revision: 10 bullet notes
```

## Do Not Do

```text
Do not jump between 20 topics.
Do not redo worker pool every day.
Do not over-study MongoDB internals before HR contact.
Do not ignore DSA completely.
Do not grind when exhausted.
Do not quote MAI Labs salary range for MongoDB.
Do not present yourself as an AI expert.
Do not undersell backend/distributed systems experience.
```
