# 10 - Senior Engineer Skills

This section covers the non-DSA, non-syntax skills that help a backend engineer operate at senior level.

These topics came from the Senior Software Engineer Roadmap 2026 video:

- clean code
- SOLID
- design patterns
- automated testing
- DDD
- event-driven design
- capacity planning
- architecture decision making
- well-architected thinking
- resume/project storytelling
- AI skills such as prompt engineering, RAG, and MCP

## Interview Summary

Senior engineers are expected to do more than write code.

They should be able to:

- make tradeoffs
- design maintainable systems
- communicate clearly
- estimate impact and risk
- test important behavior
- guide architecture decisions
- explain business value
- use AI tools responsibly
